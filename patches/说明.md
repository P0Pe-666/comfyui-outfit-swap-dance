# ComfyUI 源码补丁说明

本项目在 RTX 5060 Ti（Blackwell/sm_120）+ ComfyUI 0.34.2 + PyTorch 2.12.1+cu130 上调试时，
对 ComfyUI 源码做了 **1 处保留补丁**。ComfyUI 大版本更新后补丁会被覆盖，需按下面说明重打。

## 补丁：强制启用 Sage Attention

**文件**：`comfy/model_management.py`

**位置**：`def sage_attention_enabled():` 函数（约 1678 行）

**原代码**：
```python
def sage_attention_enabled():
    return args.use_sage_attention
```

**改为**：
```python
def sage_attention_enabled():
    return True  # 强制启用 sage attention
```

**原因**：RTX 50 系（sm_120）上 PyTorch SDPA 无高效注意力内核，Wan 系模型采样时
GPU 显示 100% 占用但实际在低效路径空转（每步可达 20+ 分钟且无温度上升）。
强制走 SageAttention（需 `pip install triton-windows sageattention`）后恢复正常速度。

**依赖**：`pip install triton-windows sageattention`

---

## 曾试用后撤销的补丁（留档避免重复踩坑）

1. **禁用 DynamicVRAM**（`comfy/cli_args.py::enables_dynamic_vram` 改为恒 False）——
   实测经典 lowvram 路径每步 25 分钟，远慢于 DynamicVRAM 智能加载，已撤销恢复默认。
2. **禁用 async weight offload**（`comfy/model_management.py` NUM_STREAMS 强制 0）——
   对性能无改善，已撤销恢复默认。

## 附：Windows 显存页面文件建议

模型 + ComfyUI 运行时内存峰值较高，建议虚拟内存（页面文件）设置为
**40960~65536 MB**（放在 NVMe 固件盘上），否则大模型加载/换入换出可能失败。
